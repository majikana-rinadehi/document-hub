- 保存

```markdown
security add-generic-password   -s "サービス名（APIキーの識別名）"   -a "$(whoami)"   -w "APIキーの値"   -U
```

- 読み出し(環境変数に代入)

```markdown
API_KEY=$(security find-generic-password -s "サービス名（APIキーの識別名）" -a "$(whoami)" -w)
```

- 読み出し(標準出力のみ)

```markdown
echo "$(security find-generic-password -s "サービス名（APIキーの識別名）" -a "$(whoami)" -w)"
```
